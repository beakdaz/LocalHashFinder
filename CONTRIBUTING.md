# Contributing

Спасибо за интерес к LocalHashFinder!

## С чего начать

1. Форкните репозиторий и создайте ветку от `main`.
2. Сборка: `BUILD.bat` или `cd engine && cargo build --release`.
3. Тесты: `cd engine && cargo test`.

## Pull requests

- Один PR — одна логическая задача (фича, багфикс, документация).
- Не коммитьте `data/`, `*.lmdb`, `*.cfg`, `*.exe`, `target/`.
- Описывайте изменения и способ проверки.

## Код

- Rust 2021, минимальный diff, следуйте стилю существующих модулей.
- UI-строки — в `engine/src/i18n.rs` (RU и EN).
- Новые CLI-команды — в `engine/src/main.rs` + документация в README.

## Вопросы

Issues на GitHub — для багов и предложений. Не прикладывайте реальные базы или дампы с персональными данными.
